## Project Overview
This project implements a back-end system following the **MVC pattern**, which separates the application logic into **Models**, **Views**, and **Controllers**. It is intended for educational purposes and as a foundation for more complex applications.

## Features
- Structured MVC architecture
- CRUD operations for core entities
- RESTful API endpoints
- Basic authentication and authorization
- Modular and scalable design
